# ফুলচিত্র (Phulchitra) — Multi-Page Private Art Archive & Digital Studio

ফুলচিত্র একটি পূর্ণাঙ্গ মাল্টি-পেজ প্রাইভেট আর্ট আর্কাইভ এবং ডিজিটাল স্টুডিও ওয়েব অ্যাপ্লিকেশন। এটি আপনার দেওয়া ডিজাইন ও রঙের প্যালেট অনুসরণ করে **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, **Prisma + SQLite**, **Sharp**, এবং **JWT + bcrypt** অথেনটিকেশন দিয়ে তৈরি।

## প্রধান পেজসমূহ (Real Multi-Page Routes)
- `/login` — সুরক্ষিত স্টুডিও লগইন গেট (রেট লিমিটিং এবং HttpOnly কুকি সেশনসহ)
- `/` — স্টুডিও গ্যালারি (মেসনরি/লিস্ট লেআউট, অবস্থা, সংকলন, প্রিয় ও সার্চ ফিল্টার)
- `/artwork/[id]` — শিল্পকর্মের বিস্তারিত ভিউ, প্রিয় চিহ্নিতকরণ ও গোপন নোট সম্পাদনা
- `/upload` — নতুন শিল্পকর্ম আপলোড (Sharp ইমেজ অপ্টিমাইজেশন ও প্রাইভেট স্টোরেজ)
- `/collections` ও `/collections/[id]` — কিউরেটেড সিরিজ ও সংকলন ব্যবস্থাপনা
- `/trash` — সফট-ডিলিট করা শিল্পকর্ম পুনরুদ্ধার বা স্থায়ীভাবে মুছে ফেলা
- `/settings` — পাসকোড পরিবর্তন, স্টুডিও প্রোফাইল, থিম ও সম্পূর্ণ JSON ব্যাকআপ এক্সপোর্ট

## সেটআপ নির্দেশিকা (Setup Instructions)

1. এনভায়রনমেন্ট ফাইল তৈরি করুন:
   ```bash
   cp .env.example .env
   ```

2. ডিপেন্ডেন্সি ইনস্টল করুন:
   ```bash
   npm install
   ```

3. ডাটাবেজ তৈরি ও নমুনা শিল্পকর্ম সিড করুন:
   ```bash
   npm run db:push
   npm run db:seed
   ```

4. অ্যাপ্লিকেশন চালু করুন:
   ```bash
   npm run dev
   ```

5. ব্রাউজারে `http://localhost:3000` খুলুন এবং ডিফল্ট পাসকোড **`ফুলচিত্র`** দিয়ে প্রবেশ করুন।
